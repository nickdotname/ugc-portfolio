# Nick Benak — UGC Portfolio

Swiss/editorial-style one-page portfolio. Next.js App Router, static export, Tailwind CSS.

## Development

```bash
npm run dev
```

## Build (static export)

```bash
npm run build
```

Output is written to `out/` and deploys to Cloudflare Pages.

See the build plan for phases, content schema, and the video ingestion pipeline.
